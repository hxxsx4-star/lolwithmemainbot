# lolwithmemainbot

**롤 같이 하자** 리그 오브 레전드 커뮤니티 디스코드 서버의 **메인 봇**입니다.
경제 · 경고 · 문의함 · 프로필 · 내전 · 롤 계정 등록을 담당합니다.

서버 로그(입장·퇴장·채널·역할·채팅·음성·제재)는
[`lolwithmelogbot`](https://github.com/hxxsx4-star/lolwithmelogbot) 이 맡습니다.

---

## 설치

```bash
git clone https://github.com/hxxsx4-star/lolwithmemainbot.git
cd lolwithmemainbot
python -m venv .venv && source .venv/bin/activate   # 윈도우: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env      # DISCORD_TOKEN, RIOT_API_KEY, GUILD_ID 입력
python bot.py
```

### 개발자 포털 설정

**Bot → Privileged Gateway Intents** 에서 아래 두 개를 켜 주세요.

- `SERVER MEMBERS INTENT`
- `MESSAGE CONTENT INTENT`

### 필요한 권한

`역할 관리` · `채널 관리` · `닉네임 관리` · `멤버 차단` · `메시지 보내기` ·
`링크 첨부` · `파일 첨부` · `스레드 만들기`

봇 역할은 **티어/라인/미등록 역할보다 위**에 있어야 역할을 지급할 수 있습니다.

### 첫 실행 후 할 일

1. `/문의함생성` — 문의함 채널에 버튼 패널을 올립니다.
2. 서버 설정 → 역할에서 **봇 역할을 미등록·티어·라인 역할보다 위로** 올립니다.
   (미등록 역할은 봇이 켜질 때 전원에게 자동으로 지급됩니다)
3. `assets/profile_bg.png` 에 프로필 카드 배경을 넣습니다. ([자세히](assets/README.md))
4. `assets/fonts/` 에 한글 폰트를 넣습니다. (없으면 카드 글자가 깨질 수 있습니다)
5. `python scripts/download_tier_emblems.py` — 티어 엠블럼을 받아 둡니다. (선택)

## 기능

### 💰 경제 — 포인트(P)

| 명령어 | 설명 |
| --- | --- |
| `/출석` | 하루 한 번 **100P**. 연속 출석일도 함께 셉니다 |
| `/포인트 [유저]` | 보유 포인트 · 순위 · 누적 음성 시간 |
| `/랭킹` | 포인트 상위 10명 |
| `/포인트지급 [유저] [포인트] [사유]` | 관리자 지급 |
| `/포인트차감 [유저] [포인트] [사유]` | 관리자 차감 (0 아래로 내려가지 않음) |

음성 채널에 있으면 **10분마다 10P**가 자동으로 쌓입니다. 잠수(AFK) 채널은 제외되고,
채널을 완전히 떠나면 10분이 채워지지 않은 자투리 시간은 사라집니다.

- 출석·지급·차감 로그 → `1535952070207610930`
- 음성 활동 적립 로그 → `1535952369978834954`

### ⚠️ 경고

| 명령어 | 설명 |
| --- | --- |
| `/경고 [유저] [횟수] [사유]` | 경고 지급 |
| `/차감 [유저] [횟수] [사유]` | 경고 차감 |
| `/경고목록 [유저]` | 경고 내역 (본인은 누구나, 남은 관리자만) |

누적 경고 **3회 이상**이면 자동으로 서버에서 차단합니다. 차단 직전에 대상에게 DM 으로
경고 내역을 보내고, 차단 사유에는 지금까지의 경고 사유를 모두 모아 적습니다.

- 경고 지급 로그 → `1535953668619116554`
- 경고 차감 로그 → `1535960186450087957`

### 🎮 롤 계정 등록

| 명령어 | 설명 |
| --- | --- |
| `/등록 [유저] [롤닉네임#태그]` | 라이엇 API 로 계정 확인 후 등록 |
| `/등록해제 [유저] [사유]` | 관리자용 등록 해제 |
| `/내계정` | 내 등록 정보와 솔로랭크 확인 |

- 본인 계정은 누구나 등록할 수 있고, **남의 계정은 서버 관리 권한**이 있어야 합니다.
- `RIOT_API_KEY` 가 있으면 실제로 존재하는 계정인지 확인하고, 라이엇이 알려준 정확한
  대소문자 표기로 저장합니다. 키가 없으면 확인 없이 등록하고 경고를 남깁니다.
- 같은 롤 계정을 두 사람이 등록할 수 없습니다.
- 등록 로그 → `1535960377014227034`

### 📝 신규 인원 등록 (`1536033191381569556`)

이 채널에 아래 양식으로 채팅을 치면 봇이 자동으로 처리합니다.

```
롤닉네임#태그/올해최고티어/주라인 부라인
예) 홍길동#KR1/M405/MID AD
```

- 서버 닉네임을 양식 그대로 바꿔 줍니다
- 티어 역할 + 주 라인 역할 + 부 라인 역할을 지급합니다 (이전 티어/라인 역할은 회수)
- 티어: `U I B S G P E D M GM C` — 마스터 이상은 뒤에 LP 를 붙일 수 있습니다
- 라인: `TOP JG MID AD SUP` (`ADC`, `JUNGLE`, `서폿` 같은 표기도 알아듣습니다)

- 태그는 영문·숫자뿐 아니라 **한글과 공백도 됩니다.** (예: `원 샷#올 킬/M45/MID AD`)

**닉네임 양식**과 **`/등록`** 이 둘 다 끝나야 미등록 역할(`1536052613538250803`)이
사라집니다.

미등록 역할은 **봇이 켜질 때 서버 전원을 대상으로 자동 동기화**됩니다. (봇 제외)
새로 들어온 사람에게도 자동으로 붙고, 닉네임을 바꾸면 다시 계산합니다.
지금 바로 다시 맞추고 싶으면 `/역할동기화` 를 쓰세요.

**기본 역할**(`config.py` 의 `Roles.DEFAULT`, 6개)도 같은 시점에 봇을 제외한
전원에게 채워집니다. 조건 없이 주는 역할이라 회수는 하지 않습니다.

> 역할이 안 붙는다면 대부분 **봇 역할이 대상 역할보다 아래**에 있어서입니다.
> `/역할동기화` 를 실행하면 원인을 그대로 알려 줍니다.

### 🎯 라인 역할 선택 (`1536153863441223760`)

`/라인패널생성` 으로 **주 라인**과 **부 라인** 패널을 올립니다.
이모지를 누르면 역할이 붙고, 같은 이모지를 다시 누르면 떨어집니다.

| 이모지 | 라인 | 주 라인 역할 | 부 라인 역할 |
| --- | --- | --- | --- |
| `LWM_LINE_1` | 탑 | `1536110430446162073` | `1536110528676634724` |
| `LWM_LINE_2` | 정글 | `1536110449576386700` | `1536110544602275900` |
| `LWM_LINE_3` | 미드 | `1536110468329115678` | `1536110565275996191` |
| `LWM_LINE_4` | 원딜 | `1536110487065067602` | `1536110580778147933` |
| `LWM_LINE_5` | 서폿 | `1536110508057436170` | `1536110603175858266` |

- 한 패널에서 **하나만** 고를 수 있습니다. 다른 라인을 누르면 이전 역할과
  이전 이모지가 자동으로 정리됩니다.
- 패널 메시지 ID 는 DB(`panels` 테이블)에 저장되므로 봇을 재시작해도 계속 동작합니다.
- 패널을 다시 만들면 **이전 패널 메시지는 반응하지 않습니다.** 지워 주세요.

### 📈 레벨

| 명령어 | 설명 |
| --- | --- |
| `/레벨 [유저]` | 음성 · 채팅 레벨과 순위 |
| `/레벨랭킹 [음성\|채팅]` | 레벨 상위 10명 |

모두 **Lv. 0** 에서 시작합니다. 다음 레벨까지 필요한 경험치는
`600 + 55 × 현재레벨` 로 늘어납니다. (Lv.0→1 = 600XP, Lv.1→2 = 655XP …)

- **음성 레벨** — 음성 채널에 있으면 **분당 2.5XP** 자동 적립.
  Lv.1 까지 약 **4시간**입니다. 소수점은 다음 분으로 이월되므로 손실이 없습니다.
- **채팅 레벨** — 메시지당 **10XP**, **60초 쿨타임**, 2글자 미만은 제외.
  Lv.1 까지 최소 60개(약 1시간)로, 음성 4시간과 비슷한 무게가 되도록 잡았습니다.

수치는 전부 `config.py` 의 `Level` 클래스에 모여 있습니다.

### 🪪 `/프로필 [유저]`

배경 이미지 위에 골드 테두리 카드로 그려서 보여줍니다.

- 좌상단 아바타 + **"롤 같이 하자"** 문구 + 서버 닉네임 + 등록된 롤 닉네임#태그
- 우상단 **보유 포인트**
- 가운데 **음성 레벨 / 채팅 레벨** 게이지와 순위(`#4위`)
- 하단 **롤 솔랭 티어 / 롤 자유랭크 티어** (엠블럼 · 티어 · LP · 승패)

티어는 라이엇 API 에서 받아오고 **10분간 캐시**합니다.
라이엇 정보가 없으면 서버 역할이나 닉네임 양식의 티어로 대신 채웁니다.

**티어 엠블럼**은 `assets/tiers/master.png` 처럼 넣으면 사용합니다.
아래 스크립트로 한 번에 받을 수 있고, 없으면 봇이 티어 색으로 크레스트를 직접 그립니다.

```bash
python scripts/download_tier_emblems.py
```

/내전생성 [제목] [룰: 하드 피어리스 | 피어리스 없음] [3판 2선 | 5판 3선 | 죽을 때까지]

`1536049980836548720` 포럼 채널에 모집 글을 올립니다.
**서버 관리 권한** 또는 `1536050031520514168` 역할이 있어야 생성할 수 있습니다.

- 글에 붙은 **참가 / 참가 취소 / 모집 마감** 버튼으로 진행합니다
- 참가자 목록에는 `/등록` 으로 등록한 **롤닉네임#태그만** 표시됩니다
- 등록하지 않은 사람은 참가할 수 없습니다
- 정원은 10명(5대5)

### 📮 문의함 (`1536033094442942565`)

`/문의함생성` 으로 버튼 패널을 올립니다. 버튼을 누르면 본인과 스태프만 볼 수 있는
비공개 채널이 만들어집니다.

| 행 | 색 | 버튼 |
| --- | --- | --- |
| 1행 | 🟢 초록 | 서버 문의 · 티어 조정 |
| 2행 | 🔴 빨강 | 분쟁 및 유저 신고 |
| 3행 | 🔵 파랑 | 내전 문의 · 기타 문의 |

같은 종류의 문의는 한 번에 하나만 열 수 있습니다.
**티켓 닫기**(문의자·스태프) / **채널 삭제**(스태프) 버튼으로 정리합니다.
