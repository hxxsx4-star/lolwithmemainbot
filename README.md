# lolwithmemainbot

**롤 같이 하자** 리그 오브 레전드 커뮤니티 디스코드 서버의 **메인 봇**입니다.
경제 · 경고 · 문의함 · 프로필 · 내전 · 롤 계정 등록을 담당합니다.

서버 로그(입장·퇴장·채널·역할·채팅·음성·제재)는
[`lolwithmelogbot`](https://github.com/hxxsx4-star/lolwithmelogbot) 이 맡습니다.

---

## 설치

```bash
git clone https://github.com/hxxsx4-star/lolwithmemainbot.git
cd lolwithmemainbot
python -m venv .venv && source .venv/bin/activate   # 윈도우: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env      # DISCORD_TOKEN, RIOT_API_KEY, GUILD_ID 입력
python bot.py
```

### 개발자 포털 설정

**Bot → Privileged Gateway Intents** 에서 아래 두 개를 켜 주세요.

- `SERVER MEMBERS INTENT`
- `MESSAGE CONTENT INTENT`

### 필요한 권한

`역할 관리` · `채널 관리` · `닉네임 관리` · `멤버 차단` · `메시지 보내기` ·
`링크 첨부` · `파일 첨부` · `스레드 만들기`

봇 역할은 **봇이 다루는 모든 역할보다 위**에 있어야 지급할 수 있습니다.

### 첫 실행 후 할 일

1. `/문의함생성` — 문의함 채널에 버튼 패널을 올립니다.
2. 서버 설정 → 역할에서 **봇 역할을 봇이 다루는 모든 역할보다 위로** 올립니다.
   (기본 · 미등록 · 서버원 · 티어 · 라인 · 게임 모드)
3. `/역할패널생성` — 역할 선택 채널에 라인 · 게임 모드 패널을 올립니다.
4. `assets/profile_bg.png` 에 프로필 카드 배경을 넣습니다. ([자세히](assets/README.md))
5. `assets/fonts/` 에 한글 폰트를 넣습니다. (없으면 카드 글자가 깨질 수 있습니다)
6. `python scripts/download_tier_emblems.py` — 티어 엠블럼을 받아 둡니다. (선택)

## 기능

### 💰 경제 — 포인트(P)

| 명령어 | 설명 |
| --- | --- |
| `/출석` | 하루 한 번 **100P**. 연속 출석일도 함께 셉니다 |
| `/포인트 [유저]` | 보유 포인트 · 순위 · 누적 음성 시간 |
| `/랭킹` | 포인트 상위 10명 |
| `/포인트지급 [유저] [포인트] [사유]` | 관리자 지급 |
| `/포인트차감 [유저] [포인트] [사유]` | 관리자 차감 (0 아래로 내려가지 않음) |

음성 채널에 있으면 **10분마다 10P**가 자동으로 쌓입니다. 잠수(AFK) 채널은 제외되고,
채널을 완전히 떠나면 10분이 채워지지 않은 자투리 시간은 사라집니다.

- 출석·지급·차감 로그 → `1535952070207610930`
- 음성 활동 적립 로그 → `1535952369978834954`

### 🛒 상점

| 명령어 | 설명 |
| --- | --- |
| `/상점` | 역할상점 / 기타상점을 둘러보고 구매 |
| `/내아이템` | 보유 아이템과 남은 기간 |
| `/색상역할생성` | [관리자] 색상 역할 9종 자동 생성 |
| `/응원역할생성` | [관리자] LCK 팀 응원 역할 10종 자동 생성 |

**모든 아이템은 30일 기간제입니다.** 영구로 팔면 두어 달 만에 다들 사고 끝나서
포인트를 쓸 곳이 없어집니다. 만료되면 시간당 도는 정리 작업이 되돌립니다.

| 분류 | 상품 | 가격 |
| --- | --- | --- |
| 🎨 역할상점 | 색상 역할 (닉네임 색) | 2,000P |
| 🎨 역할상점 | LCK 팀 응원 역할 | 1,500P |
| 🪪 기타상점 | 프로필 카드 테마 | 2,000P |
| 🪪 기타상점 | 프로필 카드 문구 (최대 14자) | 3,000P |

테마는 골드(기본) 외에 **바이올렛 · 민트 · 크림슨 · 애저 · 로즈 · 앰버 · 제이드 ·
실버 · 심연** 9종입니다. 테두리 · 박스 외곽선 · XP 게이지 · 포인트 상자 색이
통째로 바뀝니다. 팔레트는 `config.py` 의 `CARD_THEMES` 에 모여 있습니다.

색상 역할은 카드 테마와 같은 팔레트로 만들어지므로 색을 맞출 수 있습니다.

**LCK 응원 역할**은 `T1 · 젠지 · 한화생명e스포츠 · 디플러스 기아 · KT 롤스터 ·
DRX · 광동 프릭스 · 농심 레드포스 · BNK 피어엑스 · OK저축은행 브리온` 10종입니다.
팀 목록과 색은 `config.py` 의 `LCK_TEAMS` 에 있고, 시즌마다 손보면 됩니다.

`/색상역할생성` · `/응원역할생성` 을 실행한 뒤
**봇 역할을 만들어진 역할들보다 위로** 올려 주세요.

> 두 명령어는 **같은 이름의 역할이 이미 서버에 있으면 새로 만들지 않고 그것을
> 등록합니다.** 손으로 만들어 둔 팀 역할이 있어도 중복되지 않습니다.

**색상 역할과 응원 역할은 갈래가 달라 동시에 하나씩 가질 수 있습니다.**
같은 갈래에서 다른 걸 사면 이전 것은 역할과 보유 목록 모두에서 정리됩니다.

> 가격은 월 수입(출석만 3,000P / 음성 2시간 병행 6,600P)을 기준으로,
> 보통 유저가 한 달에 한두 개 유지할 수 있는 선으로 잡았습니다.
> `config.py` 의 `Shop` 클래스에서 바꿉니다.

### 📝 신규 인원 등록 (`1536033191381569556`)

이 채널에 아래 양식으로 채팅을 치면 봇이 자동으로 처리합니다.

```
롤닉네임#태그/올해최고티어/주라인 부라인
예) 홍길동#KR1/M405/MID AD
```

소개 한 번이면 **네 가지가 한꺼번에** 처리됩니다. `/등록` 을 따로 칠 필요가 없습니다.

1. 서버 닉네임을 양식 그대로 변경
2. 티어 역할 + 주 라인 역할 + 부 라인 역할 지급 (이전 티어/라인 역할은 회수)
3. 적어 낸 **롤닉#태그로 롤 계정 자동 등록** (라이엇 API 로 실제 계정인지 확인)
4. 미등록 역할을 떼고 **서버원 역할**(`1536050217332244551`) 지급

- 티어: `U I B S G P E D M GM C`
- **티어 뒤 숫자는 구간에 따라 뜻이 다릅니다.**
  아이언~다이아는 **단계 1~4** (`E4` = 에메랄드 4), 마스터 이상은 **LP** (`M405` = 마스터 405LP).
  없는 단계(`E5`)나 언랭에 붙인 숫자(`U3`)는 걸러 냅니다.
- 라인: `TOP JG MID AD SUP`
- **티어와 라인은 대문자만 받습니다.** 닉네임이 그대로 이 문자열이 되기 때문에,
  `mid` `gm` 처럼 소문자로 쓰면 통과시키지 않고 **무엇을 어떻게 고쳐야 하는지**
  짚어서 답장합니다. 잘못된 곳이 여러 개면 한 번에 모두 알려 줍니다.
- `ADC` `JUNGLE` `미드` `마스터` 같은 다른 표기도 알아보고 올바른 약자를 알려 줍니다.
- 전각 기호(`＃` `／`)는 자동으로 고쳐 줍니다.

- 태그는 영문·숫자뿐 아니라 **한글과 공백도 됩니다.** (예: `원 샷#올 킬/M45/MID AD`)

계정 등록만 실패하면(없는 계정 · 남이 이미 등록한 계정 · API 키 만료) 닉네임과
역할은 그대로 두고, 미등록 역할(`1536052613538250803`)을 남긴 채 사유를 알려 줍니다.
고쳐서 다시 적으면 그때 등록됩니다.

**미등록 역할과 서버원 역할은 항상 하나만 붙어 있습니다.** 등록을 마치면
미등록 → 서버원으로 바뀌고, `/등록해제` 하면 반대로 돌아갑니다.
이미 등록을 마친 사람도 **봇이 켜질 때 서버 전원을 대상으로 자동 동기화**되어
서버원 역할을 받습니다. (봇 제외)
새로 들어온 사람에게도 자동으로 붙고, 닉네임을 바꾸면 다시 계산합니다.
지금 바로 다시 맞추고 싶으면 `/역할동기화` 를 쓰세요.

**기본 역할**(`config.py` 의 `Roles.DEFAULT`, 6개)도 같은 시점에 봇을 제외한
전원에게 채워집니다. 조건 없이 주는 역할이라 회수는 하지 않습니다.

> 역할이 안 붙는다면 대부분 **봇 역할이 대상 역할보다 아래**에 있어서입니다.
> `/역할동기화` 를 실행하면 원인을 그대로 알려 줍니다.

### 🔔 인증 안내 자동 공지

소개 채널에 **매일 00 · 06 · 12 · 18시(KST)** 미등록 역할을 멘션하며 인증 안내를
올립니다. 새로 올릴 때 **직전 안내는 지워서** 채널이 안내로 도배되지 않게 합니다.
`/인증안내` 로 지금 바로 올릴 수도 있습니다.

문구·시각·삭제 여부는 `config.py` 의 `VERIFY_REMINDER_TEXT` ·
`VERIFY_REMINDER_HOURS` · `VERIFY_REMINDER_REPLACE` 에서 바꿉니다.

> 멘션 알림이 울리려면 미등록 역할이 **'멘션 허용'** 이거나 봇에게
> `모두 멘션` 권한이 있어야 합니다. 아니면 로그에 경고가 남습니다.

### 📈 레벨

| 명령어 | 설명 |
| --- | --- |
| `/레벨 [유저]` | 음성 · 채팅 레벨과 순위 |
| `/레벨랭킹 [음성\|채팅]` | 레벨 상위 10명 |

모두 **Lv. 0** 에서 시작합니다. 다음 레벨까지 필요한 경험치는
`600 + 55 × 현재레벨` 로 늘어납니다. (Lv.0→1 = 600XP, Lv.1→2 = 655XP …)

- **음성 레벨** — 음성 채널에 있으면 **분당 2.5XP** 자동 적립.
  Lv.1 까지 약 **4시간**입니다. 소수점은 다음 분으로 이월되므로 손실이 없습니다.
- **채팅 레벨** — 메시지당 **10XP**, **60초 쿨타임**, 2글자 미만은 제외.
  Lv.1 까지 최소 60개(약 1시간)로, 음성 4시간과 비슷한 무게가 되도록 잡았습니다.

수치는 전부 `config.py` 의 `Level` 클래스에 모여 있습니다.

### 🪪 `/프로필 [유저]`

배경 이미지 위에 골드 테두리 카드로 그려서 보여줍니다.

- 좌상단 아바타 + **"롤 같이 하자"** 문구 + 서버 닉네임 + 등록된 롤 닉네임#태그
- 우상단 **보유 포인트**
- 가운데 **음성 레벨 / 채팅 레벨** 게이지와 순위(`#4위`)
- 하단 **롤 솔랭 티어 / 롤 자유랭크 티어** (엠블럼 · 티어 · LP · 승패)

강조색과 좌상단 문구는 **상점에서 산 사람만** 달라집니다. 사지 않았으면
골드 테마 + "롤 같이 하자" 입니다.

티어는 라이엇 API 에서 받아오고 **10분간 캐시**합니다.
라이엇 정보가 없으면 서버 역할이나 닉네임 양식의 티어로 대신 채웁니다.

**티어 엠블럼**은 `assets/tiers/master.png` 처럼 넣으면 사용합니다.

| 행 | 색 | 버튼 |
| --- | --- | --- |
| 1행 | 🟢 초록 | 서버 문의 · 티어 조정 |
